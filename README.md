# GeoMapper

## Descripción

Mapeo Móvil es una aplicación creada en Flutter para ayudar a topógrafos y administradores a registrar, visualizar y gestionar terrenos desde dispositivos móviles. El sistema permite el seguimiento en tiempo real de los usuarios en campo y la administración de datos geográficos e imágenes de los terrenos.

## ¿Qué hace el sistema?

- Permite a los **topógrafos** registrar terrenos, guardar ubicaciones y subir imágenes.
- Los **administradores** pueden gestionar usuarios, roles y registros de terrenos.
- Visualiza la ubicación de los topógrafos en mapas interactivos.
- Consulta galerías de imágenes y detalles de cada terreno.
- Calcula áreas y distancias entre puntos en el mapa.

## ¿Cómo funciona?

1. **Inicio de sesión:** Acceso seguro para topógrafos y administradores.
2. **Registro de terrenos:** Captura de ubicación y datos de cada terreno.
3. **Subida de imágenes:** Asociación de fotos a los terrenos registrados.
4. **Visualización en mapa:** Muestra la ubicación y áreas de trabajo en mapas interactivos.
5. **Gestión administrativa:** Modificación, eliminación y consulta de registros y usuarios.

## Actores principales

- **Topógrafo:** Registra terrenos, sube imágenes y comparte ubicación.
- **Administrador:** Gestiona usuarios, roles y registros del sistema.

## Herramientas y tecnologías utilizadas

- **Flutter:** Framework principal para el desarrollo de la app.
- **Supabase:** Autenticación, base de datos y almacenamiento de imágenes en la nube.
- **flutter_map & latlong2:** Visualización de mapas y manejo de coordenadas geográficas.
- **geolocator & geodesy:** Obtención de ubicación y cálculo de áreas/distancias.
- **image_picker:** Selección y subida de imágenes desde el dispositivo.
- **uuid:** Generación de identificadores únicos para registros.
- **Material Design:** Interfaz moderna y fácil de usar.
